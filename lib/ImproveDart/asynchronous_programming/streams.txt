What is Stream? What are the different types of streams in Dart?
In Dart, a stream represents a sequence of asynchronous events. It’s a way to handle data that comes in over time, rather than all at once, the stream tells you that there is an event when it is ready. An ‘Event’ can either be a ‘data’ event, an ‘error’ event, or a ‘done’ event. Streams are a fundamental concept in Dart for handling asynchronous programming, allowing developers to process data as it becomes available, without blocking the execution flow

Dart provides two types of streams: single subscription or broadcast.

1. Single-subscription streams: These are streams where only one listener can listen to the stream during its lifetime. Once data is emitted or the stream is closed, it cannot be listened to again. Examples include Stream and Future.

Here’s a simple example demonstrating the usage of a single-subscription stream in Dart:
import 'dart:async';

void main() {
  // Create a stream controller
  StreamController<int> controller = StreamController<int>();
  
  // Create a stream
  Stream<int> stream = controller.stream;

  // Listen to the stream
  stream.listen(
    (int data) {
      print('Data: $data');
    },
    onError: (error) {
      print('Error: $error');
    },
    onDone: () {
      print('Stream closed');
    },
  );

  // Add data to the stream
  controller.add(1);
  controller.add(2);
  controller.add(3);

  // Close the stream
  controller.close();
}

2. Broadcast streams: These are streams where multiple listeners can listen to the stream during its lifetime. Data emitted by the stream will be received by all active listeners. This is useful when you want to broadcast events to multiple parts of your application simultaneously. To create a broadcast stream simply include StreamController.broadcast() on an existing single subscription stream.

import 'dart:async';

// Initializing a stream controller for a broadcast stream
StreamController<String> controller = StreamController<String>.broadcast();

// Creating a new broadcast stream through the controller
Stream<String> stream = controller.stream;

void main() {
  // Setting up a subscriber to listen for any events sent on the stream
  StreamSubscription<String> subscriber1 = stream.listen((String data) {
    print('Subscriber1 on Data: ${data}');
  }, onError: (error) {
    print('Subscriber1 on Error: ${error}');
  }, onDone: () {
    print('Subscriber1: Stream closed');
  });

  // Setting up another subscriber to listen for any events sent on the stream
  StreamSubscription<String> subscriber2 = stream.listen((String data) {
    print('Subscriber2 on Data: ${data}');
  }, onError: (error) {
    print('Subscriber2 on Error: ${error}');
  }, onDone: () {
    print('Subscriber2: Stream closed');
  });

  // Adding a data event to the stream with the controller
  controller.sink.add('Hello!');

  // Adding an error event to the stream with the controller
  controller.addError('Hi!');

  // Closing the stream with the controller
  controller.close();
}

🧠 Step 1 — What is a Stream? 
A Stream is a sequence of data events that come over time, not all at once. 
Each piece of data is delivered asynchronously (later in time).
You subscribe (listen) to a Stream and get notified when:
✅ new data comes
⚠️ an error happens
🚫 the stream is done (finished)

🧮 Simple Example: 
import 'dart:async';

void main() {
  print('Start');

  // A simple stream that sends 3 numbers
  Stream<int> numberStream = Stream.fromIterable([1, 2, 3]);

  numberStream.listen(
    (number) => print('Received: $number'),
    onDone: () => print('Stream Finished'),
  );

  print('End');
}

⚙️ Explanation:
“Start” and “End” print first because the stream emits data asynchronously.
Then data comes one by one.
After all data is sent, the stream calls onDone().

🧠 Real Use Cases of Streams in Flutter : 
| Use Case                     | Description                             |
| ---------------------------- | --------------------------------------- |
| **API / Firebase Live Data** | Listen for real-time database updates   |
| **User Input**               | Detect typing or scrolling continuously |
| **Sockets**                  | Real-time messages (like chat)          |
| **Location Tracking**        | Stream of location coordinates          |
| **Bluetooth / Sensor data**  | Data coming from hardware sensors       |


Q: Why do we use Streams in Flutter?
A: To handle data that changes continuously, like user input, real-time updates, or sensor data, without blocking the main thread.

🧩 Step 2 — How to listen to a Stream (the Consumer Side)

🧠 What does “listening to a Stream” mean?
Think of it like subscribing to a YouTube channel 📺
When you subscribe, you get notifications whenever a new video (event) is uploaded.
You can also unsubscribe anytime (cancel the subscription).
You might handle errors (e.g., "video not found") or end of channel (when no more videos).
That’s exactly what happens when you listen to a Stream in Dart.

import 'dart:async';

void main() {
  // Create a simple stream of numbers
  Stream<int> numbers = Stream.fromIterable([10, 20, 30]);

  print('Before listening...');

  numbers.listen(
    (value) => print('Got value: $value'), // when new data arrives
    onError: (error) => print('Error: $error'), // if something goes wrong
    onDone: () => print('Stream finished!'), // when stream ends
    cancelOnError: false, // keep listening even after an error
  );

  print('After starting to listen...');
}

Output: 
Before listening...
After starting to listen...
Got value: 10
Got value: 20
Got value: 30
Stream finished!

🧠 Explanation (simple words)

Stream emits data one by one
→ You receive each value inside (value) => print('Got value: $value').
onError :
→ Runs when something goes wrong.
onDone :
→ Runs once when the stream has finished sending all data.
cancelOnError :
→ If true, it stops listening after the first error.
If false, continues even after an error.

🎛️ StreamSubscription — the Controller of Listening

When you use .listen(), it returns a StreamSubscription object.
This gives you control — you can pause, resume, or cancel listening.

import 'dart:async';

void main() async {
  Stream<int> numbers = Stream.periodic(
    Duration(seconds: 1),
    (count) => count,
  );

  // Start listening
  StreamSubscription<int> subscription = numbers.listen((data) {
    print('Data: $data');
  });

  // Pause listening after 3 seconds
  Future.delayed(Duration(seconds: 3), () {
    print('⏸️ Paused');
    subscription.pause();
  });

  // Resume after 2 more seconds
  Future.delayed(Duration(seconds: 5), () {
    print('▶️ Resumed');
    subscription.resume();
  });

  // Cancel after 8 seconds
  Future.delayed(Duration(seconds: 8), () {
    print('🛑 Cancelled');
    subscription.cancel();
  });
}

⚙️ Explanation
.pause() → temporarily stops receiving data.
.resume() → continues listening.
.cancel() → completely stops and frees resources (very important in Flutter widgets during dispose()).

🧩 Step 3 — How to Create Streams (the Producer Side)
Now you already know:
. A Stream is a pipe through which data flows over time.
. You can listen to a stream (the consumer part).
Now we’ll learn how to produce or send data into a stream — like creating your own water tap 💧 that sends values.


🎯 There are 3 Main Ways to Create Streams in Dart
1️⃣ Predefined Stream       	 Converts existing data to a Stream	     Stream.fromIterable()
2️⃣ StreamController	         Manually add data dynamically	         StreamController().add()
3️⃣ Async Generator (async*)	 Automatically emits data using yield	 Stream<int> count() async* 


🧩 1️⃣ Stream from Existing Data
If you already have data (like a list), and you want to send it one-by-one:
import 'dart:async';

void main() {
  Stream<int> numbers = Stream.fromIterable([1, 2, 3, 4]);

  numbers.listen(
    (value) => print('Got: $value'),
    onDone: () => print('✅ Stream finished'),
  );
}
💡 Use case: When you want to process list data asynchronously.


🧩 2️⃣ Using StreamController (Manual way)
This is the most used method in Flutter apps.
You can create a StreamController → add data → other parts of the app listen.
Think of it like a “remote control” for your stream.

import 'dart:async';

void main() async {
  final controller = StreamController<String>();

  // Listening to the stream
  controller.stream.listen(
    (data) => print('📩 Received: $data'),
    onDone: () => print('✅ Stream Closed'),
  );

  // Adding data
  controller.add('Hello');
  controller.add('Dark Learner');
  controller.add('🔥 Learning Streams');

  // Must close after work
  await controller.close();
}


🧩 3️⃣ Using async* and yield (Async Generator)
This is the cleanest and modern way to create a stream.
Instead of using controllers, you just "yield" values one by one.
Example : 
import 'dart:async';

Stream<int> countStream() async* {
  for (int i = 1; i <= 3; i++) {
    await Future.delayed(Duration(seconds: 1)); // simulate delay
    yield i; // emit one value
  }
}

void main() async {
  await for (int value in countStream()) {
    print('Received: $value');
  }
  print('✅ Done');
}


🎯 Interview Tips

Q: How do you create a Stream manually?
A: By using StreamController. You can add data with add() and close it with close().

Q: What is the difference between StreamController and async*?
A: StreamController gives you manual control to add data anytime, while async* is cleaner for generating data in sequence using async code.

Q: Why must we close a StreamController?
A: To free resources and avoid memory leaks.

🧠 Step 4️⃣ — StreamController in Production Logic
You already know that a StreamController is used to create and control a Stream manually.
Think of it like this:
Controller = a remote control for your stream 📡
You can send (add) data, send errors, or close the stream whenever you want
Other parts of your app listen to this stream and react automatically

— Single-subscription vs Broadcast Streams :
there are two types of controllers in dart . 
  Single-subscription** (default) :    Only **one listener** can listen  | Common for internal app logic                                
  Broadcast** (`StreamController.broadcast()`) :  Multiple listeners** can listen | Useful for events, notifications, or multiple UI parts listening . 

  Example (single subscription ) default : 

 void main() {
final controller = StreamController<int>();

controller.stream.listen((data) => print('Listener 1: $data'));
// ❌ This will throw error if you add another listener
// controller.stream.listen((data) => print('Listener 2: $data'));

controller.add(1);
controller.add(2);
}

⚙️ Example: Broadcast Stream : 
final controller = StreamController<int>.broadcast();

controller.stream.listen((data) => print('Listener 1: $data'));
controller.stream.listen((data) => print('Listener 2: $data'));

controller.add(10);
controller.add(20);


✅ Broadcast lets multiple parts of your app receive the same event.
🧠 Commonly used in Flutter for event buses or global updates (like BLoC pattern).

Q: What is StreamController in Dart?
A: It’s a class that helps us create and manage streams manually — you can add data, send errors, and close it.

Q: When to use broadcast StreamController?
A: When multiple parts of your app need to listen to the same stream at once (like notifications, global updates).

Q: Why must we close the controller?
A: To free system memory and prevent leaks — especially important in Flutter’s dispose() method.
