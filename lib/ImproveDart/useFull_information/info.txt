What is Iterable?
A collection that can be looped. Examples: List, Set.

What is Iterator?
The object that visits each item one-by-one using moveNext() and current.

Their relationship:
Iterable gives an Iterator. Iterator reads the items.

Lazy Iterables (Very Easy Explanation) : 
Lazy Iterable means operations do not run immediately; they run only when items are accessed. Dart’s map(), where(), skip(), and take() produce lazy iterables.

Iterable vs List : 
Iterable is a lazily evaluated collection that you can loop through. List is a concrete collection stored in memory and allows index access. map() and where() return Iterable, not List.

map(), where(), forEach() — Simple & Clean Explanation : 

🔵 map() : 
Example:
var nums = [1, 2, 3];
var doubled = nums.map((n) => n * 2);
print(doubled.toList());
 
Interview Answer:
map() takes each element and transforms it into a new element. It returns a lazy iterable.

🔵 where() : 
Example:
var nums = [1, 2, 3, 4, 5];
var even = nums.where((n) => n % 2 == 0);
print(even.toList());

Interview Answer:
where() filters elements and returns only the items that satisfy the condition.

🔵 forEach() : 
Example:
[10, 20, 30].forEach((n) {
  print("Number: $n");
});

Interview Answer:
forEach() applies a function to each element but does not return a new iterable.
